How Personalized Software Changes Everything

personalize software by editing its source directly instead of configuring it. The old plugin systems and config files exist to spread the cost of a change across many users. When an AI agent can edit the source itself, that cost collapses.

For single-user software, a top-end agent can usually add a feature in a single shot. Careful code review can often be replaced by "does it seem to work?"

The catch is that the software must be open source. All you need is the source code. Closed-source tools like Claude Code can't be personalized this way.

This applies to small teams too. Instead of configuring a heavy task manager, a team can assemble the features it wants from building blocks, and keep going because the agent also rebases local changes on upstream every night.
